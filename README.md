# Jefri Junifer Pangaribuan — Swiss Editorial Minimalism

Website portofolio berbahasa Indonesia dengan layout editorial yang menggabungkan **Bold Swiss** dan **Refined Editorial**.

## Struktur

- `/` Beranda
- `/tentang/` Tentang
- `/kepemimpinan/` Kepemimpinan
- `/penelitian/` Penelitian
- `/perjalanan/` Perjalanan
- `/kolaborasi/` Kolaborasi

## Stack

HTML + CSS + vanilla JavaScript statis, tanpa dependency build. Halaman SEO-friendly dan responsif. Foto di `assets/jefri-junifer-pangaribuan.webp` berasal dari unggahan pemilik website.

## Preview lokal

```sh
python3 -m http.server 8080
```

## Deployment

Static deployment ke Vercel, dengan domain project `jefrijuniferp.vercel.app` bila tersedia. Repository GitHub yang diinginkan `jefrijunifer/jefrijuniferp` (belum dibuat apabila akses akun tidak mengizinkan pembuatan repo melalui integrasi). Website pertama di repository `jefrijunifer/jefrijunifer` tidak diubah.

## Catatan

- Tidak mengklaim metrik penelitian atau dampak yang tidak diverifikasi.
- Referensi publikasi menggunakan tautan DOI penerbit.
- Riwayat pendidikan S1 dan S2 sengaja tidak ditampilkan.
